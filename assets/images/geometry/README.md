# Decorative project artwork

Seven original generated geometric images continue the user's selected
`desktop-sequence.png` storyboard (panel 04). They use the established lilac
`#D6D4ED`, navy `#0A1628`, forest `#1B3A32` and olive `#BDB414` palette.

These are decorative index images, not screenshots or evidence of a product.
Keep empty alternative text and `aria-hidden="true"` in the lists. Case-study
screenshots and factual content remain separate and unchanged.

The image-generation tool created each standalone image using the original
storyboard as a style reference. WebP variants preserve the complete frame at
480×200, 960×400 and 1600×667 pixels; format conversion uses quality 85.
Each variant is below 150 kB. No third-party logo, code or model was copied.
